# Session 10 - Kubernetes Core Objects

This session is documented as a full working directory rather than a single screenshot file.

- **[README.md](README.md)** - overview, namespaces, ports, all eight exercises
- **[SCREENSHOT_COMMANDS.md](SCREENSHOT_COMMANDS.md)** - exact commands to reproduce every screenshot
- Each exercise directory has its own `README.md` (objective, files, commands, expected vs actual
  verified result) and an `Outputs/` directory of captured command output.

All eight exercises were executed against a live minikube cluster (Kubernetes v1.37.0,
containerd 2.3.4). No screenshots have been pasted in yet - capture them with the commands in
`SCREENSHOT_COMMANDS.md` and add them to a `screenshots/` directory.
