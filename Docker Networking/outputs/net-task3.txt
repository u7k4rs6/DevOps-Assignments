$ pwd
/home/utkuputku/Desktop/Devops-ass/Docker Networking

=========== Step 1: mount the host folder as nginx web root ===========
$ docker run -d --name nginx-bind -v "$(pwd)/bind-mount":/usr/share/nginx/html -p 8090:80 nginx:alpine
84dc09b5326c7e453c7c4b6c3ae4b9c910a53a6c47f9f995795617f9aed40973

$ docker ps --filter name=nginx-bind --format "table {{.Names}}	{{.Status}}	{{.Ports}}"
NAMES        STATUS         PORTS
nginx-bind   Up 3 seconds   0.0.0.0:8090->80/tcp, [::]:8090->80/tcp

=========== Step 2: verify the content is served ===========
$ curl -s http://localhost:8090 | grep -o "<h1>.*</h1>"
<h1>Hello students</h1>

=========== Step 3: the mount really is the same directory ===========
$ docker inspect nginx-bind --format '{{range .Mounts}}{{.Type}}  {{.Source}} -> {{.Destination}}  rw={{.RW}}{{end}}'
bind  /home/utkuputku/Desktop/Devops-ass/Docker Networking/bind-mount -> /usr/share/nginx/html  rw=true

$ ls -i bind-mount/index.html                       # inode on the host
8284778 bind-mount/index.html
$ docker exec nginx-bind ls -i /usr/share/nginx/html/index.html   # inode in the container
8284778 /usr/share/nginx/html/index.html
  ^ same inode number: it is one file, not a copy

=========== Step 4: edit on the host, re-check WITHOUT restarting ===========
$ sed -i "s|<h1>Hello students</h1>|<h1>Hello students - updated live!</h1>|" bind-mount/index.html
$ curl -s http://localhost:8090 | grep -o "<h1>.*</h1>"
<h1>Hello students - updated live!</h1>
  ^ no docker restart, no rebuild - the change is live

=========== Step 5: it works in the other direction too ===========
$ docker exec nginx-bind sh -c "echo \"<!-- written from inside the container -->\" >> /usr/share/nginx/html/index.html"
$ tail -1 bind-mount/index.html   # visible on the host immediately
<!-- written from inside the container -->

=========== Step 6: contrast - a COPY-based image does NOT update ===========
$ docker run -d --name nginx-copy -p 8091:80 nginx-hello   # index.html baked in with COPY
87d322000fab46733e814bc13685261ac636618ff00f5308b6dd139492bf010f
